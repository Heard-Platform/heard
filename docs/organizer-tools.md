# Organizer Tools

## Statement Deduplication

When participants submit statements, it's common for similar ideas to be expressed in different words. The **Manage Duplicate Statements** tool (found in the room menu under *Moderator Tools*) lets you merge these duplicates together. Select a source statement and a target statement — the source will be consolidated into the target, and all votes from the source will be carried over. You can add multiple sources to the same target, and remove any merge at any time. This keeps the voting data clean and ensures participants aren't splitting their votes across semantically identical statements.
